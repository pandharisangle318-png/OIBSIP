# Oasis Infobyte Submission Checklist

Nothing below has been done for you. Tick each item yourself, and follow the official internship instructions you received, because dates, links and rules come from Oasis Infobyte, not from this project.

## A. Before submitting - test it yourself
- [ ] Run `setup.bat` successfully
- [ ] Add your own keys to `.env` (email App Password, OpenWeatherMap key)
- [ ] Run `diagnose.bat` and fix any FAIL line
- [ ] Run `test.bat` (all automated tests should pass)
- [ ] Manually test with your real microphone: hello, time, date, search, an unclear phrase, ML question, weather, reminder, email (send one real test email to yourself), joke, custom command
- [ ] Take screenshots and put them in the `screenshots/` folder (never show `.env`)

## B. GitHub upload (your action)
- [ ] Create a public repository, for example `Python_Task1_VoiceAssistant`
- [ ] Upload the project folder contents; confirm `.env` is NOT in the repository (only `.env.example`)
- [ ] Open the repository in a private window to confirm the README displays and no secrets are visible

## C. Demo video (your action)
- [ ] Record using `docs/DEMO_VIDEO_SCRIPT.md` (first 2 seconds: full name, track name, task title)
- [ ] Upload it where the internship instructions allow and keep the link

## D. LinkedIn (your action)
- [ ] Edit `docs/LINKEDIN_POST.md`, add the GitHub and video links, include `#oasisinfobyte`, publish it

## E. Peer evaluation (your action, only if the instructions require it)
- [ ] Check the official instructions; if peer review of other interns' projects is required, complete the required number

## F. Official submission form (your action)
- [ ] Use the form link given in your official internship instructions and submit the GitHub, video and LinkedIn links
- [ ] Keep a screenshot or confirmation of the submission
