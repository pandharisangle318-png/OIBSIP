I'm happy to share Task 1 of my Python Programming internship at Oasis Infobyte: **VYOM, an intelligent personal voice assistant** built with Python.

What VYOM can do:
- Voice input with SpeechRecognition, spoken replies with pyttsx3
- Time and date, Google search, live weather (OpenWeatherMap)
- Voice-driven email with a read-back and a mandatory "yes" before sending
- Timed reminders with audible alerts, running in the background
- Natural language understanding: it answers questions like "Can you explain machine learning in simple words?" from an offline knowledge base
- Custom commands from a JSON file, a joke feature, and a modern dark PySide6 interface

Built with: Python 3.12, PySide6, SpeechRecognition, pyttsx3, smtplib, requests, python-dotenv, and an automated test suite.
